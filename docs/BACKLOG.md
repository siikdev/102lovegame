### 📷 스크린샷 OCR 기록 (오프라인 내전 소급 입력)  `우선순위: 상` `노력: L` `상태: 승인(로드맵 1순위)`
스코어보드 스크린샷을 올리면 닉네임·K/D/A·설치/해체를 추출해 **수동 기록 폼을 자동 프리필** — 라이브 세션 없이 한 내전도 나중에 사진만으로 기록.
**가치**: 세션 안 켜고 한 판들이 전적에서 누락되는 구멍을 막음. K/D·요원 데이터의 진입점.
**접근**: ① **tesseract.js (브라우저 내 CPU OCR, 무료·서버 불필요)** 로 1차 — 표 형태라 좌표 기반 파싱 가능. 닉네임↔실명 매핑 테이블(players, Supabase)로 변환 + 미매칭은 사용자 확인 UI. ② 정확도 부족 시 폴백: 수동 폼에 "사진 보면서 입력" 분할 화면. 레코드 schemaVersion 3 (players[].agent/kills/deaths/assists), 집계는 stats.js 확장 지점만. 소급 기록은 날짜별 아카이브 세션 자동 생성(11/6 백필과 동일 패턴).
**리스크**: 한글 닉네임 OCR 정확도 — 실스크린샷 몇 장으로 선검증 필요. 요원 아이콘은 OCR 불가 → 이미지 매칭 또는 수동 선택.

### 📵 시청 중 화면 꺼짐 방지 (Wake Lock)  `우선순위: 상` `노력: S` `상태: 제안` `조사: 2026-11-14`
폰으로 시청 시 화면이 꺼지며 WS 가 끊기는 근본 원인을 Screen Wake Lock API 로 해결 (현재는 복귀 후 폴링으로 복구만).
**가치**: 모바일 시청 경험의 가장 큰 구멍 제거 — 내전 멤버 대부분 폰 시청. **접근**: 뷰어 진입 시 `navigator.wakeLock.request('screen')`, `visibilitychange` 복귀 시 재획득, 미지원/거부 시 조용히 무시(기존 폴링이 안전망). Chrome/Edge 84+·Safari 16.4+(iOS 18.4 부터 홈화면 앱도)·Firefox 126+, HTTPS 필수(Pages ✓). 출처: [caniuse](https://caniuse.com/wake-lock), [해설](https://www.telerik.com/blogs/optimizing-web-applications-using-screen-wake-lock-api), [패턴](https://noscreensleep.com/screen-wake-lock/).
